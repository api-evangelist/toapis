# ToAPIs

An OpenAI-compatible AI API gateway/aggregator fronting 50+ text, image, and video models (GPT, Claude, Gemini, DeepSeek, Qwen, Sora/Veo/Kling, etc.) behind a single integration, with model routing, provider failover, unified usage tracking, and consolidated billing.

- **Provider:** https://toapis.com
- **Documentation:** https://docs.toapis.com/docs/cn
- **Base URL:** https://toapis.com/v1
- **Tags:** AI API, LLM/AI gateway, model aggregation, OpenAI-compatible, model routing, provider failover, text generation, image generation, video generation, developer tools
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 95/100

## APIs

- **ToAPIs API** — OpenAI-compatible REST API covering chat/completions, image generation, video generation, and model listing (plus Anthropic Messages and OpenAI Responses formats). Key-authenticated via Bearer token. (`https://toapis.com/v1`)

> ToAPIs exposes a public OpenAI-compatible REST API at https://toapis.com/v1 (also toapis.cn for China; homepage advertises api.toapis.com — base URLs are inconsistent and should be reconciled). Auth is Bearer sk- keys managed at https://toapis.com/console/token. No public OpenAPI/AsyncAPI/GraphQL/Postman contract is published, though OpenAI/Anthropic SDKs work due to API compatibility. Two llms.txt files (site + docs) plus extensive markdown companion pages support agent/LLM discovery. No MCP server (hosted or local) and no published agent skills exist — only client-integration guides that repoint existing coding agents at the OpenAI-compatible endpoint. Documentation is Chinese-only at present.
